# Kurone_Web

Team Kurone의 공개 이슈 관리용 저장소입니다.

이 저장소는 외부에서 사이트에 대한 버그 제보, 개선 요청, 기능 제안 등을 접수하고 관리하기 위한 공간입니다.

## 이슈 작성

새 이슈를 작성할 때는 가능하면 다음 내용을 포함해 주세요.

- **이슈코드**: 자동 생성된 이슈 코드
- **심각도**: 높음 / 중간 / 낮음
- **내용**: 문제가 발생한 상황과 재현 방법
- **다음**: 필요한 조치나 확인 사항
- **확인**: 테스트 또는 확인 결과

## 이슈 규칙

- 제목 형식: `[KW-번호] 한 줄 요약`
- 심각도 라벨: `심각도:높음` / `심각도:중간` / `심각도:낮음`
- 상태 라벨: `상태:접수` / `상태:진행중` / `상태:보류` / `상태:해결` / `상태:반려`
- 해결된 이슈는 확인 후 `상태:해결`로 변경하고 닫습니다.

## 보안

비밀번호, API 키, 액세스 토큰, 개인정보, 내부 운영 정보 및 기타 비공개 정보를 이슈나 커밋에 포함하지 마세요.

보안 문제가 의심되는 경우 공개 이슈에 민감한 내용을 그대로 작성하지 말고 별도의 비공개 연락 경로를 이용해 주세요.

## 프로젝트

공개 이슈는 Team Kurone의 작업 관리와 개선 사항 추적에 활용됩니다.
